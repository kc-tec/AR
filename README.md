# សេចក្តីផ្តើម

## យល់ដឹងពីការណែនាំសម្រាប់ការធ្វើការស្រាវជ្រាវប្រតិបត្តិដោយខ្លួនឯង

អ្នកជាសិស្សដែលចង់នាំមកការប្រែប្រួលនិងវឌ្ឍនភាពដល់សាលារបស់អ្នកដែរឬទេ? តើអ្នកគឺជាគ្រូបង្រៀន ដែលចង់កែលម្អការបង្រៀននៅក្នុងថ្នាក់របស់អ្នក ឱ្យកាន់តែប្រសើរឡើង ដែរឬទេ? តើអ្នកគឺជានាយក នាយិកាសាលាដែលចង់ស្វែងរកមូលហេតុដែលនាំឱ្យសិស្សក្នុងសាលារៀនរបស់អ្នកបោះបង់ការសិក្សា និងមិនអាចបញ្ចប់ការសិក្សារបស់ពួកគេ ដែរឬទេ? តើអ្នកជាប្រធានមន្ទីរអប់រំ យុវជន និងកីឡា ហើយអ្នកចង់ប្រមូលនូវភស្តុតាងដែលអាចទុកចិត្តបានដើម្បីគាំទ្រដល់ការសម្រេចចិត្ត ក្នុងការធ្វើផែនការយុទ្ធសាស្ត្រវិស័យអប់រំ ឬផែនការប្រតិបត្តិប្រចាំឆ្នាំ សម្រាប់អភិវឌ្ឍប្រព័ន្ធអប់រំដែរឬទេ?

ជាទូទៅ យើងតែងតែគិតថា តើធ្វើយ៉ាងណាដើម្បីឱ្យជីវិតការងាររបស់យើងបានប្រសើឡើង ឬតើយើងគួរផ្លាស់ប្តូរដោយរបៀបណាក្នុងការកែលម្អសាលារៀនកន្លែងធ្វើការ ឬ អង្គភាពរបស់យើង? ប៉ុន្តែ យើងមិនទាន់ដឹងថាត្រូវធ្វើយ៉ាងណា។ ចម្ងល់ទាំងនេះ ត្រូវបានបំភ្លឺដោយសៀវភៅបច្ចេកទេសគន្លឹះនៃការស្រាវជ្រាវប្រតិបត្តិមួយក្បាលនេះ។ សៀវភៅនេះ ត្រូវបានតាក់តែង សម្រាប់មន្ត្រីនៃមន្ទីរ និងការិយាល័យអយក. នាយក លោកគ្រូអ្នកគ្រូ ព្រមទាំង សិស្ស និស្សិត និងគរុនិស្សិត ដែលមានបំណងចង់ស្វែងរកនូវដំណោះស្រាយបញ្ហា ដែលកើតឡើងក្នុងជីវិតការងារ និងការសិក្សាដោយនាំយកមកវិញនូវការប្រែប្រួល និងវឌ្ឍនភាពតាមរយៈការស្រាវជ្រាវបែបប្រតិបត្តិ។

## រចនាសម្ព័ន្ធសៀវភៅ

សៀវភៅវនេះ ចែកចេញជា ៤ ជំពូក។

**ជំពូកទី១** ផ្តោតលើនិយមន័យនៃការស្រាវជ្រាវប្រតិបត្តិ សមាសធាតុសំខាន់ៗ និងអត្ថន័យរបស់សមាសធាតុសំខាន់ៗ ទាំងនោះ។

**ជំពូកទី២** ពន្យល់ពីវិធីសាស្ត្រនៃគម្រោងស្រាវជ្រាវប្រតិបត្តិ ចាប់ពីចំណុចចាប់ផ្តើមរហូតដល់បញ្ចប់។ ជំពូកនេះ ក៏បានបង្ហាញពីនីតិវិធីការប្រមូលទិន្នន័យ ការថតសារសំឡេង និងការវិភាគទិន្នន័យ និងសារៈសំខាន់នានានៃការឆ្លុះបញ្ចាំងឡើងវិញរបស់ការស្រាវជ្រាវ។

**ជំពូកទី៣** ពន្យល់បកស្រាយពីបញ្ហាសំខាន់ៗ នៃចរិយាសម្បទាប្រកបដោយសីលធម៌ក្នុងការស្រាវជ្រាវ (គោលការណ៍ទាំង ៥នៃក្រមសីលធម៌)។ លើសពីនេះ ជំពូកនេះក៏បានផ្តោតដល់ការស្រាវជ្រាវជាមួយកុមារ ការការពារសុវត្ថិភាព និងការអនុវត្តការពារចំពោះកុមារគ្រប់កាលៈទេសៈ។

**ជំពូកទី៤** ជាការសង្ខេបឡើងវិញនូវអ្វីដែលមាននៅក្នុងសៀវភៅនេះ និងការផ្តល់ព័ត៌មានបន្ថែមទៀតទាក់ទងនឹងការវិភាគការផាត់ចេញពីសង្គម និងយេនឌ័រ (SEGA) ព្រមទាំងការភ្ជាប់នូវទម្រង់គំរូផ្សេងៗ ដែលជាព័ត៌មានជំនួយបន្ថែមសម្រាប់ប្រើ ក្នុងអំឡុងពេលធ្វើការស្រាវជ្រាវប្រតិបត្តិ។

# គោលបំណង

សៀវភៅវនេះ មានគោលបំណងជួយឱ្យអ្នកយល់ពីដំណើរការស្រាវជ្រាវប្រតិបត្តិ តាមជំហាននីមួយៗ ដើម្បីធ្វើឱ្យអ្នកស្រាវជ្រាវថ្មីមានទំនុកចិត្តក្នុងការធ្វើគម្រោងស្រាវជ្រាវប្រតិបត្តិ។ គោលបំណងមួយទៀត គឺចង្អុលបង្ហាញឱ្យច្បាស់ថា ការធ្វើការស្រាវជ្រាវប្រតិបត្តិនេះ មិនត្រូវបានកំណត់ចំពោះតែអ្នកសិក្សា និងនិស្សិតសាកលវិទ្យាល័យនោះទេ។ សៀវភៅនេះ ត្រូវបានតាក់តែងឡើងដោយវិធីងាយយល់និងងាយប្រើ។ អ្នកនិពន្ធសង្ឃឹមយ៉ាងមុតមាំថា អ្នកអាននឹងយល់ដឹងពីគោលការណ៍ជាមូលដ្ឋាននៃការស្រាវជ្រាវប្រតិបត្តិ។ ឯកសារនេះនឹងផ្តល់ ការណែនាំច្បាស់លាស់ និងជាក់លាក់ជាមួយនឹងឧទាហរណ៍ជាក់ស្តែង ដើម្បីប្រាកដថា អ្នកអាចធ្វើតាមដំណាក់កាលងាយៗក្នុងការស្រាវជ្រាវខ្នាតតូចនិងនាំមកនូវការប្រែប្រួលនិងវឌ្ឍនភាព។

លើសពីនេះ សៀវភៅនេះ នឹងក្លាយជាឯកសារដ៏មានសារៈសំខាន់ក្នុងការពង្រឹងសមត្ថភាពរបស់អ្នកដឹកនាំ និងអ្នកគ្រប់គ្រងអប់រំក្នុងការរៀបចំផែនការយុទ្ធសាស្ត្រវិស័យអប់រំ ផែនការប្រតិបត្តិប្រចាំឆ្នាំ និងការធ្វើការសម្រេចចិត្តផ្អែកលើភស្តុតាងជាក់ស្តែង។ សៀវភៅនេះមានសារៈសំខាន់ចំពោះមន្ត្រីអប់រំក្នុងការធ្វើផែនការនិងគោលនយោបាយផ្អែកលើភស្តុតាងជាចម្បង។ ការស្រាវជ្រាវបែបប្រតិបត្តិគឺជាវិធីសាស្ត្រដ៏ល្អមួយក្នុងការស្វែងរកភស្តុតាងដែលជំរុញដល់ការលើកកម្ពស់ការចូលរួម ការសហការ និងការចូលរួមបញ្ចេញមតិរបស់សហគមន៍ ដែលជារឿយៗមិនត្រូវបានគេរាប់បញ្ចូលក្នុងការសម្រេចចិត្តនានាកម្រិតថ្នាក់ជាតិ។ ការស្រាវជ្រាវប្រតិបត្តិ នឹងជួយដល់ការអភិវឌ្ឍសមត្ថភាពរបស់អ្នក ឱ្យបានយូរអង្វែងក្នុងការធ្វើការស្រាវជ្រាវគ្រប់ពេលដែលអ្នកត្រូវការនូវភស្តុតាងសម្រាប់ធ្វើគោលនយោបាយផែនការ និងការអភិវឌ្ឍសមត្ថភាពស្ថាប័ន។

# ជំពូកទី១

## តើអ្វីជាការស្រាវជ្រាវប្រតិបត្តិ?

### ១.១- និយមន័យ

ការស្រាវជ្រាវប្រតិបត្តិអាចមានអត្ថន័យច្រើនយ៉ាង។ ប៉ុន្តែ ក្នុងសៀវភៅនេះ បានកំណត់និយមន័យថា៖

> ការស្រាវជ្រាវប្រតិបត្តិ គឺជាការសិក្សាខ្នាតតូចសម្រាប់បុគ្គល ក្រុម ឬ អង្គភាព ដែលចង់ស្វែងរកមូលហេតុជាក់លាក់ឱ្យបានស៊ីជម្រៅពីបញ្ហាដែលកើតមាននៅ កន្លែងធ្វើការដើម្បីធ្វើឱ្យមានការប្រែប្រួល និងវឌ្ឍនភាពផ្អែកលើភស្តុតាងនៃការស្រាវជ្រាវ។

### ១.២- សមាសធាតុសំខាន់ៗ

ទោះបីមានការឱ្យនិយមន័យខុសៗគ្នាក៏ដោយ ការស្រាវជ្រាវប្រតិបត្តិមានសមាសធាតុសំខាន់ៗមួយចំនួនដូចជា៖

* វដ្តនៃការស្រាវជ្រាវត្រូវមាន «ការធ្វើផែនការ ការអនុវត្ត និងការឆ្លុះបញ្ចាំងឡើងវិញ» ដែលតែងតែកើតឡើងសារចុះសារឡើងមិនចេះចប់
* មានការផ្តោតលើសកម្មភាពច្បាស់លាស់ ដើម្បីការប្រែប្រួល និងវឌ្ឍនភាព
* ជាការសិក្សាខ្នាតតូច មានលក្ខណៈជាបុគ្គល សេរី និងមានការចូលរួមពីអ្នកពាក់ព័ន្ធ
* មានលក្ខណៈជាប្រព័ន្ធ វិន័យ ក្រមសីលធម៌ និងភាពច្បាស់លាស់
* មានលក្ខខណ្ឌផ្អែកលើស្មារតីស្មោះត្រង់ និងតម្លាភាពចំពោះការឆ្លុះបញ្ចាំងពីខ្លួនឯង
* ដំណើរការស្រាវជ្រាវមានលក្ខណៈមិនចេះចប់ និងមិនមានព្រំដែនច្បាស់លាស់ណាមួយ
* លើកទឹកចិត្តឱ្យមានការបើកចំហ
* លក្ខណៈសហការមានដូចជា ការសន្ទនា និងការធ្វើការជាមួយគ្នាដើម្បីពង្រឹងចំណងទំនាក់ទំនង។

ដំណើរការនៃការស្រាវជ្រាវប្រតិបត្តិ តែងតែមានទម្រង់ច្បាស់លាស់ ដែលផ្តើមដោយការកំណត់បញ្ហាដើម្បីធ្វើស្រាវជ្រាវ (មើលគំនូសតាងទី១)។

**២- ការអនុវត្ត និងការសង្កេត៖** ប្រមូលទិន្នន័យតាមរយៈការសម្ភាសជាលក្ខណៈបុគ្គល និងជាក្រុម ដោយការថតសំឡេង និងវិភាគទិន្នន័យ។

**៣- ការឆ្លុះបញ្ចាំងឡើងវិញ៖** តើអ្នកបានស្រាវជ្រាវ ដោយប្រកាន់ភ្ជាប់នូវគោលការណ៍ក្រមសីលធម៌ ប្រកបដោយភាពស្មោះត្រង់และតម្លាភាព ដែរឬទេ? តើអ្នកមានភស្តុតាងដើម្បីគាំទ្រឱ្យមានការប្រែប្រួល និងវឌ្ឍនភាព ដែរឬទេ? តើអ្នកអាចឆ្លើយសំណួរស្រាវជ្រាវប្រកបដោយប្រសិទ្ធភាព ដែរឬទេ? តើអ្នកត្រូវការស្រាវជ្រាវក្នុងវដ្ត(ជុំ)ផ្សេងទៀត ដែរឬទេ?។

### ១.៣- គោលបំណង

គោលបំណងនៃការធ្វើការស្រាវជ្រាវប្រតិបត្តិគឺធ្វើឱ្យមានភាពស៊ីចង្វាក់គ្នា។ គោលបំណងទាំងនោះ គឺដើម្បីកំណត់បញ្ហាដែលកើតឡើងក្នុងជីវិតការងាររបស់បុគ្គល ក្រុម ឬអង្គភាព ហើយជំរុញ និងលើកទឹកចិត្តឱ្យធ្វើការស្រាវជ្រាវប្រកបដោយទំនុកចិត្ត និងប្រមូលរកភស្តុតាងក្នុងការធ្វើការប្រែប្រួល និងវឌ្ឍនភាព។

### ១.៤- វិសាលភាព

វិសាលភាពនៃគម្រោងស្រាវជ្រាវប្រតិបត្តិជាមូលដ្ឋាន សំដៅទៅលើប្រធានបទនានា និងការកំណត់ចំនួនអ្នកចូលរួម។ ជាក់ស្តែងវិសាលភាពនៃការស្រាវជ្រាវផ្អែកលើបញ្ហា ដែលអ្នកចង់ធ្វើការសង្កេតនោះ។ ឧទាហរណ៍ លោកគ្រូ អ្នកគ្រូចង់ធ្វើការស្រាវជ្រាវនៅក្នុងថ្នាក់រៀន ដែលគ្រាន់តែតម្រូវឱ្យសិស្ស ២ ឬ ៣ នាក់មកចូលរួម។ ក្នុងករណីបែបនេះ ការស្រាវជ្រាវមានរយៈពេលខ្លីប៉ុណ្ណោះ (៣ ទៅ ៤ សប្តាហ៍) និងត្រូវធ្វើឡើងក្នុងសាលារៀនដែលខ្លួនបង្រៀន។

ក្នុងករណីនាយកសាលាចង់សិក្សាស្វែងរកមូលហេតុ ដែលសិស្សថ្នាក់ទី៦ រៀនខ្សោយខាងអំណាន គាត់អាចនឹងចំណាយពេលវែង ព្រោះគាត់ត្រូវធ្វើការសម្ភាសជាមួយអ្នកចូលរួមច្រើនប្រភេទ ដូចជា គ្រូ សិស្ស និងឪពុកម្តាយជាដើម។ ហេតុនេះ ដំណើរការស្រាវជ្រាវនឹងអាចចំណាយពេលប្រហែល ៦ទៅ៨ សប្តាហ៍ ហើយទីកន្លែងនឹងអាចផ្លាស់ប្តូរគ្រប់ពេល អាស្រ័យលើទីតាំងសាលារៀន និងកន្លែង ដែលឪពុកម្តាយសិស្សជ្រើសរើសធ្វើការណាត់ជួប។

ក្នុងករណី មន្ត្រីមន្ទីរអយក. កំពុងធ្វើការស្រាវជ្រាវពីអត្រាបោះបង់ការសិក្សាឬការផាត់ចេញពីសង្គម នោះការសិក្សាស្រាវជ្រាវ នឹងចំណាយពេលវែង ដោយអ្នកចូលរួមមានច្រើនប្រភេទ ដូចជា នាយកសាលា សិស្ស ឪពុកម្តាយ សមាជិកសហគមន៍...។ល។ ក្នុងករណីនេះ គម្រោងការស្រាវជ្រាវប្រតិបត្តិនឹងមានក្របខណ្ឌពេលវេលាច្បាស់លាស់ ចន្លោះពី ២ទៅ៣ ខែ រីឯទីតាំងនៃការស្រាវជ្រាវនឹងមានវិសាលភាពធំជាងមុន ដោយធ្វើដំណើរតាមស្រុក ឃុំ ភូមិ ដើម្បីសម្ភាសអ្នកចូលរួមក្នុងសាលារៀន និងសហគមន៍។

នាយក នាយិកាសាលា និងមន្ត្រីអប់រំ ការិយាល័យអយក. មន្ទីរអយក. នឹងត្រូវការភស្តុតាង ពីការសិក្សាស្រាវជ្រាវប្រតិបត្តិ ដើម្បីបញ្ចូលទៅក្នុងផែនការយុទ្ធសាស្ត្រវិស័យអប់រំ និងផែនការប្រតិបត្តិប្រចាំឆ្នាំ។ ក្នុងករណីនេះ ពិតជាមានសារៈសំខាន់ណាស់ ក្នុងការរៀបចំគម្រោងស្រាវជ្រាវឱ្យបានទាន់ពេលដែលនាំឱ្យទទួលបានលទ្ធផលស្រាវជ្រាវសម្រាប់បញ្ចូលក្នុងផែនការ។ ការរៀបចំតារាងពេលវេលា របស់គម្រោងស្រាវជ្រាវ គឺជាមធ្យោបាយមួយដែលជួយសម្រួលដល់ការពិនិត្យតាមដានវឌ្ឍនភាពការងារ និងធានាថា ការស្រាវជ្រាវអាចសម្រេចបានលទ្ធផលទាន់ពេលវេលា (មើលតារាងទី១)។
